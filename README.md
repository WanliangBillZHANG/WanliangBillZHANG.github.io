# Wanliang Zhang — personal academic website

A single-page academic profile for Wanliang Zhang, an urban climate meteorologist working on atmospheric boundary-layer modeling, turbulence, and urban climate.

The site includes research, education, publications, conferences, teaching/service, awards, and contact information.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server
```
